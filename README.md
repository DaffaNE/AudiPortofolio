## Getting Started

No build tools or package installation are required for the static website.

1. Clone the repository:

   ```bash
   git clone https://github.com/DaffaNE/AudiPortofolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd AudiPortofolio
   ```

3. Open `index.html` in your browser.

   Alternatively, use the Live Server extension in Visual Studio Code for local development.
